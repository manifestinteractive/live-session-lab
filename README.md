# live-session-lab
Exploring real-time video, accessible interfaces, and AI-assisted development with LiveKit, React, and TypeScript.

The repository contains public development plans and AI development scaffolding. The application has not been built.

Start with the [development plan](planning-docs/README.md) for the scope and review phases.
The planned interface uses shadcn/ui components and Tailwind CSS v4.

See [AI development setup](docs/ai-development.md) for Codex tools and validation status.
